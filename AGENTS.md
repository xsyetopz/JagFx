# AGENTS.md

JagFx reads, writes, renders, and edits Old School RuneScape `.synth` sound effects. It is Kotlin Multiplatform (JDK 21 toolchain) with a Compose editor, a Clikt CLI, and npm packages under `packages/` built from `:bindings`.

## Commands

The Gradle build is not wired into `just` yet, so Kotlin work runs through `./gradlew`:

```bash
./gradlew check                     # tests, spotlessCheck, detekt
./gradlew :sharedUI:jvmTest         # one module's tests
./gradlew spotlessApply             # fix Kotlin formatting
./gradlew :desktopApp:run
./gradlew :bindings:syncNpmPackages # copy Kotlin/JS and Kotlin/Wasm output into packages/
```

Compiler warnings are errors, and library modules use explicit API mode.

## Project Rules

- Keep binary round-trip fidelity for every file in `references/synths/` that round-trips today.
- JSON tests for files with a known binary asymmetry compare against `SynthCodec.encode(SynthCodec.decode(bytes).patch)`, not the original bytes.
- Ask before adding a Gradle or npm dependency, and say why existing APIs fall short. After a Gradle dependency change, run `./gradlew --write-verification-metadata sha256 help`; never use lenient verification.
- Ask before editing `docs/synth-format-spec.md` unless the task is format-doc work.

## Code Map

- `:core:model` holds immutable types (`Patch`, `Voice`, `Envelope`, `Filter`) that validate ranges in `init` through `SynthLimits`. `:core:format` holds `SynthCodec` and `SynthJson`. `:core:engine` renders. `:core:vorbis` decodes `.jagvorbis` samples.
- DSP field names follow `docs/synth-format-spec.md` (`startValue`, `endValue`, `duration`, `targetLevel`).
- The editor in `:sharedUI` flows `EditorIntent` -> `reduce` (`EditorReducer.kt`) -> `EditorState`, driven by `EditorViewModel`. Platform services are interfaces in `EditorServices.kt` with one implementation per platform.
- Editor colors live in `ui/theme/` (`JagFxColors`, `SynthPalette`), sizes in `JagFxDimens`, and every user-facing string in `ui/i18n/` (`UiString` plus one `Strings*.kt` per language).
- Common tests reach `references/` files as hex fixtures generated by `GenerateHexFixturesTask` in `build-logic/`.

## Format Notes

- `.synth` files are big-endian: ten voice slots, then a four-byte loop footer.
- `USmart16` and `Smart16` variable-length integers are read and written in `SynthDecoder` and `SynthEncoder`.
- The filter field always follows `Offset` (spec §6.7); `0` means no filter.
- Partial amplitude `0` ends the partial list in binary.
