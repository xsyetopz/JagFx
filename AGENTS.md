# AGENTS.md

## Commands

- Use `./gradlew check` for tests, `spotlessCheck`, and detekt.
- Use `./gradlew :sharedUI:jvmTest` for module tests.
- Use `./gradlew spotlessApply` for Kotlin formatting.
- Use `./gradlew :desktopApp:run` to run the desktop app.
- Use `./gradlew :bindings:syncNpmPackages` to copy Kotlin/JS and Kotlin/Wasm output into `packages/`.
- Use `just` for TypeScript, Markdown, and hook checks.
- Treat compiler warnings as errors.
- Use explicit API mode in library modules.

## Project Rules

- Commit each finished slice as you work.
- Keep binary round-trip fidelity for every file in `references/synths/` that round-trips today.
- Compare JSON tests for binary-asymmetric files with `SynthCodec.encode(SynthCodec.decode(bytes).patch)`.
- Build on existing APIs first.
- Add Gradle or npm dependencies with strict verification.
- After each Gradle dependency change, run `./gradlew --write-verification-metadata sha256 help`.
- Edit `docs/synth-format-spec.md` for format documentation work.

## Code Map

- `:core:model` holds immutable types (`Patch`, `Voice`, `Envelope`, `Filter`) with ranges validated in `init` through `SynthLimits`.
- `:core:format` holds `SynthCodec` and `SynthJson`.
- `:core:engine` renders audio.
- `:core:vorbis` decodes `.jagvorbis` samples.
- DSP field names follow `docs/synth-format-spec.md` (`startValue`, `endValue`, `duration`, `targetLevel`).
- The `:sharedUI` editor flows from `EditorIntent` through `reduce` (`EditorReducer.kt`) to `EditorState`, driven by `EditorViewModel`.
- Platform services use interfaces in `EditorServices.kt` with one implementation per platform.
- Editor colors live in `ui/theme/` (`JagFxColors`, `SynthPalette`).
- Editor sizes live in `JagFxDimens`.
- User-facing strings live in `ui/i18n/` (`UiString` plus one `Strings*.kt` per language).
- Common tests use `references/` files as hex fixtures generated by `GenerateHexFixturesTask` in `build-logic/`.

## Format Notes

- `.synth` files use big-endian ordering with ten voice slots followed by a four-byte loop footer.
- `SynthDecoder` and `SynthEncoder` read and write `USmart16` and `Smart16` variable-length integers.
- The filter field follows `Offset` as described in spec §6.7; `0` represents the filter state.
- Partial amplitude `0` marks the end of the partial list in binary.
